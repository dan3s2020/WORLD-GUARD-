# WORLD GUARD — current version contract

1. `index.html` is the sole active application entry point and is preserved byte-for-byte as the new baseline.
2. Future modifications must be narrow, reproducible and scoped to the requested behavior; avoid deleting working features or importing old simulator code.
3. Preserve all `docs/` verbatim conversation and requirements material. Never treat historical design/verification reports as proof about the new HTML.
4. Synthetic simulation, placeholder values, browser-only local neural policies, real external GPU inference, and live multiplayer are distinct capabilities; do not mislabel one as another.
5. Desktop and mobile UI behavior, free camera navigation, agent visualization, replay and training functionality must be verified independently before claims of completeness.
6. Do not connect this game to real infrastructure, uncontrolled agents or payments without the appropriate verified safety and permission boundaries.

The original (now obsolete) implementation-specific contract is archived without modification as `docs/history/UX-CONTRACT_LEGACY.md`.
