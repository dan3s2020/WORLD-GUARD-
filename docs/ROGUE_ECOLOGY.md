# WorldGuard — persistent synthetic rogue ecology (2026-10-25)

## Source requirement (Romanian user feedback)
> "atentie,si rogue agents trebuiesc sa evolueze,si nu au cum sa dispara mereu,adica local undeva sigur sunt la cineva ,dar poate inca nu sunt publice,nu au infectat nimic,ci doar evolueaza,incearca sa se copieze,sa se inmulteasca,sa devina din ce in ce mai mici si sa fie din ce in ce mai destepti,etc,sca agentii nostrii sa aiba cu cine se duela"

Interpretation: *within the game*, rivals must have persistent, sometimes latent lineages that mutate and replicate in a bounded local population, and compete with defenders. Their existence outside this simulator is a hypothesis, **not an established fact**.

## Implemented

- `sim/rogue-ecology.mjs`: one permanent latent rival reservoir per simulated city plus initially active rivals; none are executable malware or external accounts. Dormant reservoirs change abstract genes over simulated steps without attacking anything.
- Reproduction clones and mutates **data-only phenotypes**. The evolving genes are stealth, adaptation, reproduction propensity and abstract compactness. `footprint` is a dimensionless game quantity, not measured binary size or a real evasion capability.
- Bounded to 72 simulated rival agents. No real network, filesystem infection, unauthorized access, propagation routines, malware packing, or self-deployment.
- Three abstract rival tactics (`decoy`, `probe`, `overload`) are selected by learned per-agent weights. Duel outcomes are affected by defender choice, defender's actual simulated task result, and rival genome. Win/loss modifies fitness, tactic estimates, energy, and a bounded defender-learning reward delta.
- Rival state survives day transitions; JSON checkpoint stores full populations and RNG state; old `worldguard-spatial-v1` saves without an ecology initialize one on import. Malformed genotypes or removal of every protected latent reservoir are rejected.
- Frame snapshots record rival counts and generation; the existing HUD and training ledger display active/latent rivals and duel outcomes. Historical playback reads archived statistics rather than the current ecology.
- Existing safety veto and human-review pause are still owned by `sim/life.mjs`, and rivals cannot bypass them.

## Why this is a simulator, not proof of external rogue presence

The duel payoff, traits, and tactics are deliberately **fictional abstractions**. They allow repeatable co-evolution experiments and comparison with frozen/random defenders, but do not establish that unknown autonomous threats exist in someone else's device. No code in the project is permitted to seek, infect, replicate onto, or control real hosts.

## Verification and limitations

Isolated local ecology tests passed (four). The repository has new isolated and integrated tests in `tests/rogue-ecology.test.mjs`; comprehensive Node/browser execution is not yet independently verified because the GitHub Actions environment failed even on the prior unmodified branch before running test steps.

This is still not a general planetary adversarial RL environment: rival tactics are abstract and finite, and defender neural features only expose the existing `rogue` context flag. Visual rogue avatars, arbitrary world-object attacks, natural selection across new task families, independent policies in Laya, and real-world risk assessment remain future work.

## Run

From the repository root on the rogue branch:

```powershell
npm ci
npm run build:game
npm test
powershell -ExecutionPolicy Bypass -File .\BUILD_AND_PLAY.ps1
```

The checked-in `game.bundle.js` is not regenerated by GitHub file API writes; **build before launching**. `BUILD_AND_PLAY.ps1` performs the bundle build and tests.
